## 1. 背景与目标

利用业余时间系统补芯片知识，按三大块组织：

- **工艺**：器件演进、光刻、刻蚀/薄膜/注入/CMP、先进封装（含 RDL/TSV/混合键合）、良率与失效；
- **理论设计**：模拟（器件/bandgap/LDO/运放/ADC/DAC/PLL/版图）、数字（RTL/验证/综合/STA/DFT/低功耗/后端）、基础理论；
- **行业**：代工/IDM、设备材料、EDA/IP、HBM 与先进封装、出口管制、会议与信息源。

目标不是背知识点，而是建立"能看懂论文/拆解/财报，能判断信息真伪"的框架。本文件记录会话层面的约定与结论；具体知识沉淀在 `学习笔记/` 对应目录。

## 2. 记录约定

1. **一题一篇**：`学习笔记/<块>/<日期>-<主题>.md`，使用 `模板-学习笔记.md`；同一主题只在原文件上更新，不新建重复文件。
2. **笔记结构**：一句话结论 → 原理/机制 → 关键数字 → 工程/产业现状 → 疑问 → 来源。
3. **证据分级**：`[事实]`（有公开来源/数据）、`[推测]`（基于原理的推断）、`[待核实]`（看到但未交叉验证）；传闻与营销口径一律 `[待核实]`。
4. **归档模式**：每个对话开场确认一次"自动上传"或"问过再上传"；自动模式直接写入并推送，问过模式在回答末尾询问。默认自动。
5. **索引同步**：各块 README 与 `学习笔记/README.md` 保持一致。
6. **只增不删**：纠错用"修正"标注，保留原判断以便回溯。

## 3. 学习地图（骨架，待逐项填充）

### 3.1 工艺

- **节点与器件**：Planar → FinFET → GAA/纳米片；同一"节点"下 PPA 与成本的实测差异。
- **光刻**：DUV 浸没、EUV 13.5 nm、High-NA EUV、多重曝光；掩模、OPC、随机缺陷。
- **前道工艺**：刻蚀（各向异性/选择比）、薄膜沉积（ALD/CVD/PVD）、离子注入与退火、CMP。
- **先进封装**：RDL、TSV、CoWoS/InFO、混合键合、Chiplet；封装为何成为瓶颈。
- **良率与可靠性**：DFM、WAT/CP/FT、常见失效模式（与已有失效分析资料互相对照）。

### 3.2 理论设计

- **模拟**：gm/ID、失配（Pelgrom）、噪声模型；bandgap/LDO/运放；SAR/ΔΣ ADC、电流舵 DAC；PLL 抖动；版图匹配与 ESD。
- **数字**：SystemVerilog/UVM、综合与 SDC、CDC、DFT、UPF 低功耗、后端签核。
- **基础**：信号与系统、控制理论、半导体物理、概率与噪声基础。

### 3.3 行业

- **算力与存储**：AI 加速器架构、HBM 代际、Chiplet 生态。
- **制造格局**：台积电/三星/Intel 代工、设备（ASML/AMAT/LAM/TEL/KLA）、材料。
- **EDA 与 IP**：三巨头格局、国产 EDA 进展、出口管制实际影响。
- **信息源**：ISSCC、VLSI Symposium、Hot Chips、IEDM、SemiAnalysis、公司财报与拆解报告。
