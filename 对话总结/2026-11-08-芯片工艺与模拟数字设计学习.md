## 1. 背景与目标

利用业余时间系统补芯片相关知识，范围包括：

- **芯片工艺**：器件演进、光刻、刻蚀/薄膜/注入/CMP、先进封装、良率与可靠性；
- **模拟设计**：器件与模型、基础模块（bandgap/LDO/运放）、数据转换器、时钟、版图；
- **数字设计**：RTL 与验证、综合与 STA、DFT、低功耗、后端流程；
- **行业前端**：AI 加速器与 HBM、先进封装产能、EDA 格局、出口管制、顶级会议动态。

目标不是背知识点，而是建立"能看懂论文/拆解/财报，能判断信息真伪"的框架。本文件是**总入口**：记录学习框架、已确认结论与索引；具体专题笔记在此基础上生长。

## 2. 记录约定（本会话的工作方式）

1. **每条笔记五段式**：一句话结论 → 原理/机制 → 关键数字（节点、参数、良率、份额等）→ 产业现状或工程取舍 → 疑问与来源。
2. **标注证据等级**：`[事实]`（有公开来源/数据）、`[推测]`（基于原理的推断）、`[待核实]`（看到但未交叉验证）。传闻与营销口径一律标 `[待核实]`。
3. **新结论落地**：更新本文件 → 文末「结论更新记录」追加一行 → 更新 `对话总结/README.md` 索引 → 提交推送。
4. **拆分规则**：单个专题超过约 200 行，或需要大量图表/公式时，拆成独立文件（命名 `2026-11-08-<专题>.md`），本文件只保留摘要与链接。
5. **不删除**：任何笔记只增不删；纠错用"修正"标注，保留原判断以便回溯。

## 3. 学习地图（骨架，待逐项填充）

### 3.1 芯片工艺

- **节点与器件**：Planar → FinFET → GAA/纳米片；同一"节点"下 PPA 与成本的实测差异。
- **光刻**：DUV 浸没、EUV 13.5 nm、High-NA EUV、多重曝光；掩模、OPC、随机缺陷。
- **前道工艺**：刻蚀（各向异性/选择比）、薄膜沉积（ALD/CVD/PVD）、离子注入与退火、CMP。
- **先进封装**：CoWoS/InFO、混合键合、Chiplet、HBM 集成；封装为何成为瓶颈。
- **良率与可靠性**：DFM、WAT/CP/FT、常见失效模式（与已有失效分析资料互相对照）。

### 3.2 模拟设计

- **器件与模型**：MOS 小信号、gm/ID 方法、失配（Pelgrom）、噪声模型。
- **基础模块**：电流镜、bandgap、LDO、两级/折叠/Class-AB 运放、稳定性与补偿。
- **数据转换**：SAR ADC、ΔΣ ADC、电流舵 DAC；ENOB/SFDR/INL 的实测口径。
- **时钟**：PLL/环振、相位噪声与抖动、时钟树。
- **版图与可靠性**：匹配布局、寄生、衬底噪声、ESD/latch-up。

### 3.3 数字设计

- **RTL 与验证**：SystemVerilog、UVM、形式验证、覆盖率闭环。
- **综合与 STA**：SDC 约束、时序例外、跨时钟域（CDC）检查。
- **DFT**：scan、BIST、JTAG、测试成本与覆盖率权衡。
- **低功耗**：UPF、电源域、DVFS、时钟门控。
- **后端**：floorplan、CTS、布线、签核（IR drop/EM/DRC）。

### 3.4 行业前端

- **算力与存储**：AI 加速器架构、HBM 代际、Chiplet 生态。
- **制造格局**：台积电/三星/Intel 代工、设备（ASML/AMAT/LAM/TEL/KLA）、材料。
- **EDA 与 IP**：三巨头格局、国产 EDA 进展、出口管制实际影响。
- **信息源**：ISSCC、VLSI Symposium、Hot Chips、IEDM、SemiAnalysis、公司财报与拆解报告。
