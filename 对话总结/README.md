# 对话工作总结

这里保存用户与 AI 助手每一轮重要对话的工作总结，便于跨会话回顾与接续。

## 规则

1. **新对话开场**：AI 会先询问——本次对话是否需要新建 GitHub 仓库保存总结、是否把总结更新到本目录。
2. **文件命名**：`<开始日期>-<主题>.md`，例：`2026-11-07-D类功放分立验证平台.md`。
3. **结论更新**：对话出现新结论（实测数据、选型决定、验证通过/失败、方案变更、推测被证实或推翻）时，更新对应文件，并在文末「结论更新记录」追加一行（日期 + 结论 + 证据/状态）。
4. **状态标记**：每份总结头部标注 进行中 / 已暂停 / 已完结。
5. **新文件**：从 `模板-新对话总结.md` 复制，按模板填写。
