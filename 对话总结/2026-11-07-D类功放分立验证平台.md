## 1. 背景与目标

为 Codec + 数字 D 类 PA 项目做**分立功能验证平台**：AD9708 DAC → TI 式分立 BD PWM（误差放大环 + 三角波比较）→ HIP2210 栅极驱动 → HB10N200S BTL 半桥 → LC → 差分负载。载波目标 384 kHz，输入为单端正电压 DAC（TIPD108 原版是 ±2 V、500 kHz）。

## 2. 已确认结论

1. **DAC 缩幅解决毛刺（2026-11-07，用户确认）**：DAC 输出目标从约 0～1 V 收到约 0.25～0.75 V（单端名义）后，正弦峰值附近 MOS 输出毛刺消失；占空比电阻未动。
2. **机理线索（待 VBOOT/VGS/SW 实测确认）**：按 A0 电阻（R1=18k、R4=41.8k）估算，全幅理论占空比 ≈92.5%→8.9%，缩幅后 ≈71.6%→29.8%；最短低电平命令脉冲从 ~195 ns 增至 ~740 ns，自举补电窗口扩大 → 高侧驱动不再在峰值段欠压。
3. **代价**：约用中间 128/256 个 DAC 码（理想量化 SNR ≈ −6 dB）；负载差分基波 ≈0.418×PVDD（12 V 时约 5 V 峰）。缩幅只是排查手段，不长期使用。
4. **最终方向**：改 PWM 占空比电阻——R1（上臂）定中点、R4/R3 比值定斜率；把最高占空比封顶在 ~80%，避免栅极驱动长时间接近 100%。
5. **居中选型表（R2=R3=10k 假设，中点 50%）**：
   - A 组（半幅 0.25～0.75 V）：A1 20k/51k、**A2 22k/62k（默认）**、A3 23.2k/69.8k、A4 24k/75k、A5 24.9k/80.6k；最高 D 分别 ≈76%/81.5%/85.3%/87.5%/89.5%。
   - B 组（恢复全幅 0～1 V）：B1 16k/33k、B2 16k/36k；最高 D ≈82.7%/88.5%。
   - 通用式：R1 = 40·R4/(50+R4)（kΩ，R2=R3=10k 时精确居中），最高 D ≈ 50% + R4/2。
6. **实焊值反推法（R1=18k 已确认）**：功率级禁用扫 3 个 DC 码，拟合 D=m·VIN+b →
   k = R4/R3 = −m·(VOH−VOL)；VB = b·(VOH−VOL)/(1+k)；R2 = VB·R1/(VREF−VB)；R4 = k·R3。
   只需再读 R3 一颗丝印即可全闭环，不必拆板读全部电阻。

## 3. 未决问题 / 待测

- 缩幅前后同触发对照：PWM_MOD、PWM_HIP、VBOOT（HB−HS 谷值）、高侧 VGS、SW——区分"前端饱和"与"自举欠压"哪个是根因。
- R2/R3/R4 实焊值（10k、41.8k 仅为计算口径，未实测确认）。
- 改电阻后的带载验证：两臂一致性、1 kHz 正弦 THD 观察、波峰谷最短脉宽与自举余量。

## 4. 下一步（用户执行）

1. **A0 基线**：保存可回退 DAC 固件；拍照两臂实焊（R1/R2/R3/R4/Cc、R5/R6/R7/C3、Rg、RDT、CBOOT）；功率级禁用，扫码 64/127/128/191，记录 VINA/B 实测电压、PWM_MOD 占空比、实测 VOH/VOL、R3 丝印。
2. 数据发回 AI → 校准选型表 → 买电阻。
3. 每轮只换 R1+R4 一对，其余固定；先 DC 三点再上低频正弦、最后 1 kHz。
