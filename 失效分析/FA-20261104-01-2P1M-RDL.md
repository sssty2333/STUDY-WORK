## 0. 结构变更说明（本次失效的背景）

- 原结构：2P1M（P1 在下 / M1 Cu / **P2 在上**）
- 现结构：1P1M——**去掉上面一层 P**（原 P2），RDL 顶层金属裸露，介质湿气/机械屏障减半

```
        ┌───────────────┐
        │  Solder bump  │  类型待确认（SAC / Cu pillar）
        ├───────────────┤
        │  UBM / 焊盘   │  直接落在 M1 Cu 上（待确认）
        ├───────────────┤
        │  M1  Cu RDL   │  2–8 µm 电镀 Cu + Ti/Cu 种子层 ← 顶层，暴露
        ├───────────────┤
        │  P（原 P1）    │  PI / PBO，5–10 µm
        ├───────────────┤
        │  芯片钝化层    │  SiN / SiO2
        ├───────────────┤
        │  Al pad       │
        └───────────────┘
```

- **需与供应商确认**：P 材料（PI / PBO？）、剩余 P 在 Cu 上还是下、bump 类型、封装形式（WLCSP？）、line/space 与 Cu/P 厚度。

## 1. 失效现象

- 对象：GL002（D 类功放），RDL 2P1M→1P1M 改版批
- 失效数量 / 总数量：**16 / 77 ≈ 21%**（2026-11-04 用户最终确认；此前口述 20、邮件草稿 19 均作废）
- 发现环节：可靠性 **AC 试验（无偏压高压蒸煮）** 后 **FT 终测**
- 现象：**PVDD 对 GND、OUT 对 GND 漏电**（对话中另见"VBAT"，VBAT 与 PVDD 是否同一 pin 待确认）；漏电流 ~100µA 级，正常规格几百 nA
- 模式一致性：同一失效模式，系统性（非随机颗粒）
- EMMI 委托单号：20261000262

## 2. 使用与应力条件

- AC = **无偏压高压蒸煮**（PCT 类，纯湿度应力）——具体温度/湿度/时长**待确认**（关键：蒸煮期无偏置 → 枝晶在蒸煮中难形成）
- FT 漏电测试电压：**待确认**（决定"低压 100µA=短路型 vs 高压才 100µA=结型"）
- 无其他异常应力记录

## 6. 失效机理假设与排除

| # | 假设 | 支持证据 | 反对证据 | 判定 |

| H2 | PI/Cu 界面分层 + 吸湿 | 去 1P → 湿气屏障减弱 | 无 | 待 C-SAM |

| H4 | ECM 枝晶桥接 | — | 蒸煮期无偏置，枝晶难形成；**但蒸煮后 FT 加电/存储期有偏置窗口，未完全排除** | 次要，待验证 |
| H5 | 介质击穿 / Cu 渗入 PI（介质裕量减半） | 变更直接削弱隔离 | 无 | 待验证 |
| H6 | ESD 钳位管结漏电 / 细丝短路 | pin 对 GND 必有 ESD 管；EMMI 阴性**不能排除**（大结弥散、被金属挡、偏置不足、打坏成细丝则本不发光） | 系统性 21% 不像单次 ESD 事件；I-V/温度可判 | 待验证 |
| H7 | 封装路径（塑封料吸湿/键合/引线框） | AC 蒸煮对封装同样有效 | 无 | 待取 die 隔离 |
| H8 | 钝化裂纹 → 水汽通道 | 去 1P 机械保护减弱 | 无 | 待 C-SAM/切片 |
| H9 | 下层金属/有源区损伤（应力重分布、潜在缺陷暴露） | 应力/湿气场贯穿全片，损伤落在最弱层 | 无 | 待电学+截面 |
