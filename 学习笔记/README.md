## 怎么记

1. **命名**：`<日期>-<主题>.md`，例 `2026-11-08-RDL工艺难点.md`。
2. **模板**：[模板-学习笔记.md](./模板-学习笔记.md)。
3. **证据分级**：`[事实]`（有公开来源/数据）、`[推测]`（基于原理的推断）、`[待核实]`（看到但未交叉验证）；传闻与营销口径一律 `[待核实]`。
4. **一题一篇，只增不删**：同一主题只在原文件上更新并追加修订记录；纠错用"修正"标注，保留原判断。
5. **索引**：每块 README 维护本块索引，归档后同步更新。

## 归档模式（每个对话开场确认一次）

- **自动上传**：回答完直接写入/更新对应块的笔记，更新索引，提交推送，结束时告知 commit。
- **问过再上传**：回答末尾问一句「要不要把这题总结进<块>？」，用户同意后再归档推送。

默认自动上传；用户在开场说"问过再上传"就按问过模式执行，中途不重复询问。
